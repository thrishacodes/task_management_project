
# Task Management Application

## 📌 Description
The Task Management Application is a responsive web application that helps users create, manage, update, and track their daily tasks easily. It provides a simple and user-friendly interface to organize tasks and improve productivity.

## ✨ Features
- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks using browser local storage
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in your web browser.
3. Start adding and managing your tasks.

## 🎯 Project Objective
To understand web development fundamentals, task management functionality, CRUD operations, and responsive user interface design.
